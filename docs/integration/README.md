# Integration Guides

These guides describe how external tool providers and agents connect to OpenTool Mesh.

- [Tool Provider Guide](./tool-provider-guide.md): publish a tool with ENS identity, 0G manifest storage, 0G KV capability indexing, and AXL invocation metadata.
- [Agent Integration Guide](./agent-integration-guide.md): discover tools by capability, verify manifests, invoke through AXL, and persist trace/report provenance.

Use the local demo first if you are validating the repository mechanics. Use the provider runbook when you are ready to write to real ENS, 0G, and AXL-backed services.
