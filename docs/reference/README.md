# Reference Docs

`docs/reference/` contains quick lookup material for concepts, commands, and short explanations. It is intended for readers who have already completed setup and want to confirm terminology or CLI usage without reading source code.

## When To Read This

- You have read the root README and want a quick reminder of terms in the `publish -> discover -> verify -> call -> trace -> report` loop.
- You are preparing to run the demo but want the shortest command explanation, expected inputs, outputs, and use cases.
- You are reading architecture docs, example code, or the dashboard and need a consistent definition for terms such as `manifest`, `trace`, `tool node`, or `audit report`.

  Explains core terms, object relationships in the runtime loop, and common commands for `publish`, `discover`, `verify`, `call`, and `demo`.
